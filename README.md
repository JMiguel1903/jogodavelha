# 🎮 Jogo da Velha em Java

Projeto desenvolvido em **Java** como prática dos conceitos iniciais de programação.

## 📌 Sobre o projeto

Este projeto consiste em um **Jogo da Velha** executado pelo terminal, permitindo que dois jogadores disputem uma partida alternando entre os símbolos **X** e **O**.

O jogo possui um tabuleiro **3x3** e verifica as jogadas para identificar quando um jogador venceu ou quando a partida terminou em empate.

## 🛠️ Conceitos utilizados

* Variáveis e tipos de dados
* Estruturas condicionais (`if/else`)
* Estruturas de repetição (`while`)
* Matrizes (`char[][]`)
* Métodos
* `Scanner` para entrada de dados
* Validação de jogadas
* Controle de turnos
* Lógica de programação

## 🎯 Objetivo

O objetivo do projeto foi praticar **lógica de programação e fundamentos de Java**, desenvolvendo um jogo simples e funcional a partir do zero.

## ▶️ Como executar

1. Tenha o **Java JDK** instalado.
2. Clone este repositório.
3. Abra o projeto em uma IDE, como IntelliJ IDEA, Eclipse ou VS Code.
4. Execute a classe principal.
5. Siga as instruções exibidas no terminal.
